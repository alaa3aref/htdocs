# GREENS Kindergarten Management System

GREENS is a production-ready, Arabic Egyptian, RTL kindergarten management platform for student lifecycle management, classroom operations, supervised attendance, parent communication, files, media, and reporting.

## Technology stack

- PHP 8.3 or newer
- MySQL 8.0 or newer using InnoDB and utf8mb4
- Apache hosting, compatible with Hostinger
- Server-rendered HTML, custom CSS, and vanilla JavaScript modules

## Development phases

1. Project Foundation & Structure Creation
2. Architecture-approved database implementation
3. Domain and application implementation
4. UI implementation from approved design references
5. Testing, deployment, and operational readiness

## Engineering Constitution

The Engineering Constitution is the single source of truth. All contributors, including AI systems, must follow it. No architecture, naming, technology, folder, security, or coding-standard change is permitted without a project-owner-approved, versioned constitutional amendment.
