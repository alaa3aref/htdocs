# Future Project Analyzer

The Project Analyzer is a future capability and is not implemented in Phase 1.

It is read-only by default and must follow the GREENS Engineering Constitution. It will assess folder integrity, imports, assets, dependencies, duplicate code and design values, responsive behavior, accessibility, performance, security, database consistency, API consistency, and QR workflow consistency. It must provide evidence, severity, remediation guidance, and false-positive records. It may not modify code, configuration, data, or production systems without separately reviewed authorization.
