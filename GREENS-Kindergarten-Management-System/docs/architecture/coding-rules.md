# Coding Rules

Phase 1 contains no business logic. Future implementation must follow the Constitution:

- PHP 8.3+, strict types, PSR-12, and PSR-4 under `App\\`.
- Use server-side validation, policies, typed DTOs, repositories, services, and response classes as documented.
- Use semantic HTML, custom CSS design tokens, and vanilla JavaScript ES modules.
- Do not add frameworks or unapproved dependencies.
- Do not duplicate business logic, components, styles, permission checks, or validation rules.
- Do not commit secrets, personal data, logs, uploads, backups, or generated reports.
- Document and test every feature before release.
